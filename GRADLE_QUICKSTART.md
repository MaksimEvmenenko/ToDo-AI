# Gradle Migration - Quick Start

## ✅ Migration Complete!

All Gradle files created and configured.

---

## 🚀 Commands

```bash
# Build
./gradlew clean build

# Run
./gradlew bootRun

# Test
./gradlew test

# Build JAR
./gradlew build

# Run JAR
java -jar build/libs/todo-ai-1.0.0.jar
```

## 📦 Created Files

- build.gradle
- settings.gradle  
- gradle.properties
- gradlew (Unix/Mac)
- gradlew.bat (Windows)
- gradle/wrapper/gradle-wrapper.properties

## 📋 Maven → Gradle

| Maven | Gradle |
|-------|--------|
| mvn clean install | ./gradlew clean build |
| mvn spring-boot:run | ./gradlew bootRun |
| mvn test | ./gradlew test |
